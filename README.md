# Threadline for Samsung

This repository hosts signed Android installers and update manifests for Threadline. Keep Google Messages and OpenBubbles installed and signed in on your phone.

From the [latest release](https://github.com/Grant5745/threadline-releases/releases/latest), download **Threadline.apk**. On your Samsung, open **My Files → Downloads**, tap the APK, then tap **Install** or **Update**. Android will ask permission to install the file if needed.

Threadline checks [update.json](https://github.com/Grant5745/threadline-releases/releases/latest/download/update.json) for the current version. Each release keeps its own APK and matching manifest.
